Private, dated human accessibility observations for pages and key journeys. No scan or conformance score.

== Description ==

Six guided human checks with W3C references, page or journey scope, outcome, assignee, test date, private note, evidence URL, filtered list and guarded CSV. Unrecorded checks remain unknown. Administrator-only; no public output, remote fetch, automated test, or WCAG conformance claim. English and Polish strings included.

== Installation ==

1. Upload the ZIP and activate.
2. Open Accessibility Checks in the admin and create a specific page or journey observation.
3. Filter, correct, repeat or export observations as a work log.

== Frequently Asked Questions ==

= Does this prove WCAG conformance? =

No. These are limited human observations and cannot establish sitewide conformance.

= Who can read notes? =

Only users with manage_options. Assignees do not receive access merely by assignment.

= What happens on uninstall? =

All checklist posts and their private metadata are erased. Deactivation retains them.
