# Accessibility Checklist 0.1.1 release QA

Date: 5 November 2026. This version fixes the named guidance container issue documented for the immutable [0.1.0 release](QA-0.1.0.md).

- Artifact: `digicyfr-accessibility-checklist-0.1.1.zip`, 12 allowlisted files, SHA-256 `44af037d477301dec4a9d3fc18247a2dee123da6fb0f8d465e9c4663e11b1266`. `scripts/release.py --verify` matched its manifest and source. The checksum sidecar was generated by that script.
- The exact ZIP installed, activated, deactivated and reactivated in a disposable WordPress 7.1, PHP 8.3.33, MariaDB 11.4.13 site. The integration fixture passed, including the `role="group"` regression assertion, permission checks, guarded CSV and uninstall checks.
- Chromium opened the exact ZIP's new-observation admin form at 390px. Axe-core 4.10.3 checked `.dacl-wrap` against WCAG 2 A/AA, 2.1 A/AA and 2.2 AA tags: zero definite violations. The browser accessibility tree exposed a group named “Human check instructions”; the DOM has the same `role` and `aria-label`. The document width was 390px at a 390px viewport. [Axe and accessibility-tree result](evidence/0.1.1/axe-form.json) · [form screenshot](evidence/0.1.1/new-form-390px.png).
- Axe could not finish a native-control color-contrast check. This is recorded as inconclusive, not a pass. The 0.1.0 browser QA covers the wider validation, save, filter, CSV and private-access flow; the 0.1.1 integration reran those code paths without other runtime changes.

The test used synthetic data on a local disposable WordPress site. A human screen-reader session, multisite and a customer-specific host have not been tested. Browser and axe results do not establish WCAG conformance of the plugin or a host website.

The published GitHub `v0.1.1` ZIP and checksum sidecar were downloaded without authentication. The sidecar verified, and the downloaded ZIP was byte-identical to the browser-tested local ZIP. The protected `release/0.1.1` branch and annotated tag resolve to commit `51fbc35232e7e4d8a869bc04c143c8d4199ba0d5`; main and release-branch CI passed. The GitHub release is stable for self-hosted manual ZIP installation with the limits above disclosed.
