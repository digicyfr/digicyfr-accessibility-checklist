# Website release copy — 0.1.0

## English

**Digicyfr Accessibility Checklist** is a free, open-source WordPress plugin for private human accessibility observations. An administrator records one dated check on a named page or key journey, including the outcome, assignee, note and optional evidence link. Six short prompts link to W3C guidance. Filter the private list and export a guarded CSV work log. Unrecorded checks are unknown; the plugin does not scan, fix, score or certify a website.

Tested locally with WordPress 7.1, PHP 8.3.33 and MariaDB 11.4.13. GPL-2.0-or-later. Version 0.1.0 uses manual ZIP updates. Download the ZIP and upload it at Plugins → Add New → Upload Plugin. Public source and ZIP links are pending publication.

## Polski

**Digicyfr Accessibility Checklist** to darmowa wtyczka WordPress o otwartym kodzie, służąca do prywatnego zapisywania ręcznych obserwacji dostępności. Administrator zapisuje jeden datowany test dla nazwanej strony lub ważnej ścieżki użytkownika, wraz z wynikiem, osobą odpowiedzialną, notatką i opcjonalnym odnośnikiem do dowodu. Sześć krótkich wskazówek odsyła do materiałów W3C. Prywatną listę można filtrować i eksportować jako zabezpieczony plik CSV. Niezapisane testy pozostają nieznane; wtyczka nie skanuje, nie naprawia, nie ocenia punktowo ani nie certyfikuje witryny.

Przetestowano lokalnie z WordPress 7.1, PHP 8.3.33 i MariaDB 11.4.13. Licencja GPL-2.0-or-later. Wersja 0.1.0 jest aktualizowana ręcznie plikiem ZIP. Pobierz ZIP i wgraj go przez Wtyczki → Dodaj nową → Wyślij wtyczkę. Publiczne odnośniki do kodu i ZIP zostaną dodane po publikacji.
